# 冲印破框 · Frame Escape Print v1.0

将用户提供的照片转化为**冲印破框构图**：一张真实的相片冲印边框被放置在纯色背景之上，照片中最具延伸方向感的元素——飞檐、拱桥、花枝、山峰——从白色边框之外延展进入背景色块之中。

核心信条：**相框本是边界，却容不住那一笔向外的力量。**

Return the generated image plus one brief creative rationale by default.

---

## 核心视觉逻辑

本风格由三层精密结构组成：

1. **纯色背景场（Background Field）**：从照片主色调提取的一种单一平涂色彩，填满整个画布；
2. **相片冲印边框（Photo Print Frame）**：白色厚边框（含底部相机品牌文字）放置在背景上，位置偏离中心；
3. **破框延伸主体（Escaping Subject）**：照片中最具方向延伸感的元素，在保持真实照片质感的前提下，从白色边框外溢出，延伸进纯色背景之中。

三层结构形成"现实从边界破出"的视觉张力。

---

## Decision Priority

1. **识别破框主体**：找到照片中最具**方向延伸感/动势**的元素（最重要）。
2. **提取背景色**：从原图主色调提取1个单一色彩，平涂为背景。
3. **确定相框位置**：相框偏向一侧，让破框元素有足够的"出框空间"。
4. **确定破框方向**：顺应破框主体的自然延伸方向，不强行改变。
5. **保持照片真实质感**：相框内外的照片部分均保持完整的摄影质感，不做插画或简化。
6. **添加相机品牌标注**：底部白色框内印有相机型号文字。

- 仅将最终提示词和参考图发送给图像生成服务。

## Step 1：识别破框主体（Escaping Subject Analysis）

仔细观察照片，找出具有以下特征的元素：

### 高优先级破框候选
| 元素类型 | 延伸方向特征 | 示例 |
|---------|------------|------|
| **中式飞檐/屋脊** | 两翼向上扬起，脊顶向上尖锐延伸 | 古建筑屋顶 → 上方或左上方破框 |
| **拱桥结构** | 弧形桥拱向两侧和下方延伸 | 石拱桥 → 左侧或左下破框 |
| **树木/花枝** | 枝条向外生长，具有不规则延展性 | 盛花树枝 → 左侧或上方破框 |
| **山峰/崖壁** | 垂直向上或斜向延伸的地貌 | 雪山顶 → 上方破框 |
| **塔楼/尖顶** | 垂直向上的建筑结构 | 钟楼/灯塔 → 上方破框 |
| **道路/铁轨** | 斜向穿越、向远处消逝的线性结构 | 公路/铁轨 → 前方/斜向破框 |
| **飞翔的鸟群** | 向天空散射延展 | 飞鸟 → 上方破框 |
| **水柱/瀑布** | 垂直向下流动 | 瀑布 → 下方破框 |
| **悬挂的植物/藤蔓** | 自然垂落 | 藤萝 → 下方或侧下破框 |

### 破框主体判断规则
- 选择**整张照片中最具视觉张力和延伸动势**的单一元素或结构
- 破框主体应在原图中占据**清晰可见的边缘区域**
- 优先选择具有**明确方向感**的元素（斜向、垂直向上、弧形延展）
- 若多个元素都有延伸感，选择**体量最大**或**方向最明确**的一个

---

## Step 2：背景色提取

从原图中提取**1个单一主色调**，作为背景平涂色：

| 场景色调 | 背景色范围 |
|---------|----------|
| 夜景/暗色调 | 深海军蓝、深钴蓝、深墨绿 |
| 古建筑/土黄色调 | 温暖米色、沙色、卡其色 |
| 晴空/水面 | 淡天蓝、粉蓝、清空蓝 |
| 草地/植物 | 柔和苔绿、浅橄榄绿 |
| 夕阳/暖光 | 暖橙褐、暗玫瑰 |
| 雾霾/阴天 | 暖灰、冷灰 |

### 背景色处理规则
- 背景色为**纯色平涂**，无渐变、无纹理、无噪点
- 色彩的明度/饱和度可从原图色调适当调整（通常降低饱和度15~25%，使背景安静退后）
- 背景色与照片内容之间形成可识别的色彩对话，但不强烈冲突

---

## Step 3：相片冲印边框规范

### 边框样式
- **边框材质**：纯白色，均匀宽度，四边一致（类似传统彩色冲印照片边框）
- **边框宽度**：约为照片区域宽度的10~15%（宽边框）
- **边框质感**：干净、光滑，无做旧或颗粒
- **底部白边**：底部白边**明显更宽**（类似老式相片冲印格式），为文字区域

### 品牌标注文字
- 左下角：**相机品牌型号**（如 `NIKON Z 50`、`FUJIFILM X-E1`、`SEAGULL DF 2-ETM`）
- 右下角：**品牌Logo或辅助文字**（`Nikon` / `FUJIFILM` / Seagull飞鸟Logo）
- 文字为极小的**打字机体或等宽字体**，深灰色
- 若用户原图包含此信息则直接使用，否则根据照片推断合适的相机型号

### 边框位置
- **不居中**——相框刻意偏移，为破框元素留出更多空间
- 偏移方向与破框方向**相反**（破框向左 → 相框偏右；破框向上 → 相框偏下）
- 偏移幅度：约相框宽度的20~40%

---

## Step 4：破框构图规则

### 破框深度
- 破框主体从白色边框内连续延伸，溢出边框**20~50%**的主体高度或宽度
- 破框部分保持与框内部分**无缝衔接**（这是同一张连续照片的一部分，不是贴图）
- 破框区域外，背景色包围着延伸出的主体

### 破框边缘处理
- 破框主体**溢出边框的边缘**：干净裁切（不是撕纸毛边！区别于其他撕裂风格）
- 相框边缘：白色框线清晰，如同真实相片的印刷边框
- **照片在框内与框外的质感完全一致**——都是真实摄影质感

### 破框方向查找表
| 破框主体 | 推荐破框方向 | 相框偏移方向 |
|---------|-----------|------------|
| 飞檐/屋脊 | 上方或左上 | 相框偏右下 |
| 拱桥 | 左侧或左下 | 相框偏右 |
| 花枝/树枝 | 左侧或左上 | 相框偏右 |
| 山峰 | 上方 | 相框偏下 |
| 塔楼尖顶 | 上方 | 相框偏下 |
| 道路/铁轨 | 前方斜下 | 相框偏后方 |
| 飞鸟 | 上方散射 | 相框偏下 |

---

## Step 5：提示词编译规范

编译为四段英文提示词：

**段落1 - 画布与背景**：
整体画布描述，单一平涂背景色（具体色值），无纹理无渐变，垂直或正方形画幅。

**段落2 - 相片冲印边框**：
白色厚边相框位置（偏右/偏下/居中偏移方向），底部宽白边含相机型号文字，边框尺寸比例，框内保留原图真实摄影质感。

**段落3 - 破框主体**：
破框主体的精确描述（元素类型、延伸方向、溢出深度），强调与框内无缝连续，保持真实照片质感。

**段落4 - 质感与约束**：
照片质感要求（真实摄影，无插画化），明确禁止事项（禁止撕纸毛边/禁止插画简化/禁止多个破框元素）。

---

## Step 6：生成工作流

1. 仔细观察用户提供的照片；
2. 建立破框分析：识别最具延伸感的破框主体 + 其自然延伸方向；
3. 从原图提取背景主色调；
4. 确定相框在画布上的偏移位置（让破框方向有空间）；
5. 确定破框深度（溢出边框的量）；
6. 推断或从原图读取相机品牌型号文字；
7. 编译四段英文提示词；
8. 以用户照片为参考生成；
9. 返回生成图像和中文创作思路。

---

## 质量检查门（Quality Gate）

- 是否识别了照片中最具延伸方向感的破框主体？
- 背景色是否为从原图提取的单一平涂色（无纹理）？
- 相框是否有清晰的白色厚边框 + 底部品牌文字？
- 相框位置是否偏向破框反方向，给破框元素留足空间？
- 破框主体是否与框内内容无缝连续（不是拼贴感）？
- 破框主体和框内照片是否保持真实的摄影质感？
- 破框边缘是否是干净裁切（不是撕纸毛边）？
- 是否只有一个破框元素（不多不少）？

---

## 硬性禁止（Hard Avoids）

- 将照片转化为插画、水彩或矢量简化（必须保留真实摄影质感）；
- 使用撕纸毛边处理破框边缘（这是干净裁切风格）；
- 多于一个破框元素；
- 背景使用渐变、纹理或做旧效果（必须是纯色平涂）；
- 相框居中放置（必须偏移以平衡破框延伸）；
- 相框无底部品牌标注文字；
- 相框内外照片质感不一致。
